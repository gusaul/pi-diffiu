# Pi Diffiu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `@gusaul/pi-diffiu`, a public Pi package with a fullscreen side-by-side Git diff viewer and Tree-sitter syntax spans that preserve property, method, parameter, and other syntactic distinctions.

**Architecture:** The package keeps Git parsing, viewport interaction, and rendering in a Pi extension module. A separate syntax module owns grammar selection, full-document parsing, parent-aware role classification, and line-local spans. The extension builds virtual documents per diff side once per file/width rebuild, wraps spans only after parsing, and retains Pi highlighting as a fallback.

**Tech Stack:** TypeScript (ESM), Node native test runner, Tree-sitter native bindings and grammars, Pi extension/TUI APIs, npm, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-24-pi-diffiu-design.md`

## Global Constraints

- Publish as public MIT package `@gusaul/pi-diffiu` from `gusaul/pi-diffiu`.
- Declare Pi packages as `peerDependencies` with `"*"`; declare Tree-sitter and shipped grammars as runtime dependencies.
- Support Go, JavaScript, TypeScript, TSX, JSON, Python, and Rust in v1.
- Parse a complete virtual source document once per diff side; never syntax-parse wrapped fragments or isolated lines.
- Retain Pi `highlightCode()` fallback for unregistered grammars and all parser faults.
- Do not require Neovim, language servers, or user-local configuration.
- Use TDD: each behavioral change gets a test observed failing before its implementation.
- Do not publish to npm until the user has authenticated and explicitly authorizes the external publish action.

## Review Focus

- Added/deleted-only lines must retain their original side coordinates and never inherit syntax spans from the opposite side.
- Strings and comments spanning multiple lines must remain classified correctly after virtual-document reconstruction.
- Unicode and wide characters must not desynchronize syntax spans, wrapping, or changed-character backgrounds.
- A Tree-sitter native-load or parse failure must open the viewer with Pi fallback rather than reject `/diff`.
- `npm pack` must contain runtime JS, extension entrypoint, and all required manifest fields but exclude tests and development-only material.
